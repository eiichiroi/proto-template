# 決めたこと

決めたことと、その理由の記録。**あとで変えにくいこと、迷って決めたこと**だけを書く（画面の細かい調整は、書かない）。

## 書き方

- 状態は、**決定**か**保留**の2つだけ
- 取り消した決定は、**削除する**（履歴は git に残る）。方向を変えたら、新しい内容と理由を書く
- 新しい決定は、末尾に追加する

```
### D1：〔決めたことを一文で〕

- 日付：YYYY-MM-DD
- 状態：決定／保留（保留なら、何が分かれば決められるか）
- 理由：〔なぜそう決めたか〕
- 採用しなかった案：〔案と、採用しなかった理由〕
- 見直す条件：〔どうなったら、考え直すか〕
```

---

〔ここに、決めたことを追加していく〕
