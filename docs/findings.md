# 検証で分かったこと

試して分かった**事実**の記録。方針が変わっても残るもの（外部サービスの挙動、データの構造、性能の限界など）を書く。

## 書き方

- 1件ごとに、日付、何を試したか、何が分かったか、**根拠**（どのデータ・ログ・実例か）を書く
- **事実と解釈を分ける。**解釈や推測は、「推測」と明記する
- **未確認の点**を、必ず書く（何を、どうすれば確かめられるか）
- 新しいものを、末尾に追加する。古い事実が、のちに覆ったら、書き直す（取り消した内容は残さない）

```
## YYYY-MM-DD：〔何を調べたか〕

- **試したこと：**〔条件、件数、期間、設定〕
- **分かったこと：**〔事実〕
- **根拠：**〔samples のどの実例、どのログか〕
- **推測：**〔事実から言えそうなこと。確かではない〕
- **未確認：**〔まだ分かっていないこと。確かめ方〕
```
