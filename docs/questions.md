# 仮説と質問

確かめたいこと（任意）。ユーザーへのヒアリング、利用場面の確認、数字の見積もりなど、**作るものが動いても、見失ってはいけないこと**を書く。

## 書き方

- 仮説には、**成立の基準**（何が分かれば成立とするか）を、先に書く
- 方向が動いたら、新しい仮説を**追加**する（既存の仮説は書き換えない。成立・不成立の結果は、「判定」に書く）
- 質問は、仮説との対応が分かるように書く
