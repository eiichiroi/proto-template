# 実例集

**入力と、確認した期待値**の一覧です。解析や判定を直すたびに、全件を回して、結果が期待と合うかを確かめる（回帰の確認）ために使います。

## 何を置くか

- **入力：**ID、URL、ファイル名など、同じ条件で再現できるもの
- **期待値：**人が確認した、正しい結果（種別、数値、状態など）
- **確認した日と、メモ：**現実の状態は変わる（在庫、価格、仕様）ので、いつの状態かを書く。ずれたら、更新するか、入れ替える
- 種類ごとに、数件ずつ集める。**実例が少ない種類ほど、判定の穴が見つかりやすい**ので、厚めに集める

## 生データ（HTML、ログ、スクリーンショットなど）について

**個人情報・機密を含まなければ、生データを置いてよい**です。ケースバイケースなので、置く前に、次を確かめてください。

| 確認すること | 内容 |
|---|---|
| 個人情報・機密 | 氏名、住所、郵便番号、電話番号、メールアドレス、アカウント名、Cookie・トークン、社内情報が入っていないか。**ページの上部（ヘッダー）に、お届け先などが入ることがある** |
| 権利・規約 | 取得元のデータの著作権や、利用規約（再配布の禁止など）に反しないか |
| 大きさ | 1ファイルが大きい（数MB）と、リポジトリが重くなる。必要な部分（構造が分かる断片）だけにできないか |
| 再現に必要か | 構造が変わったときの回帰テストなど、生データでないと確かめられないか。ID と期待値だけで足りるなら、生データは置かない |

置かないもの（置けないもの）は、`samples/private/` に入れる。ここは `.gitignore` で除外されている。

## 置き方

```
samples/
  README.md            この文書
  samples.json         実例の一覧（入力と期待値）
  raw/                 生データ（置いてよいものだけ）
  private/             個人情報・機密を含むもの（コミットしない）
```

`samples.json` の例は、[samples.example.json](samples.example.json) を参照。
